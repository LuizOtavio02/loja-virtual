Projeto de uma loja virtual desenvolvido com foco em aprendizado de desenvolvimento web utilizando PHP, JavaScript e MySQL.

O objetivo do projeto é simular um e-commerce simples, permitindo visualizar produtos, categorias, carrinho de compras e realizar pedidos.


# 🚀 Tecnologias utilizadas

- PHP
- HTML5
- CSS3
- JavaScript
- MySQL
- Twig (Template Engine)
- PHPMailer
- Bootstrap 5
- Git

# 📦 Funcionalidades

- Listagem de produtos
- Listagem por categorias
- Carrinho de compras
- Página de finalização de compra
- Envio de email de contato
- Sistema de rotas em PHP
- Renderização de páginas com Twig
- Consumo de API utilizando JavaScript (Fetch)
